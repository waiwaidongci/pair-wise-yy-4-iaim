# 水下考古测绘基准校正与复核台

直接打开 `index.html` 使用。

- 每个潜次只能有一个生效基准，须登记方位、比例尺和误差；旧基准自动转为历史留档。
- 误差超过 5% 或比例尺缺失（含未登记基准）时，该潜次标记只能「待校正」，不进入时间线与导出。
- 修改基准或更换标记潜次后，关联标记按新基准重算并回到「待复核」，旧坐标留档但不计入统计。
- 类型/状态筛选与列表/时间线视图会持久化，刷新后状态一致；状态在加载时按生效基准重新同步。

代码分三个业务文件：

- `js/rules.js` —— 业务规则：基准校验、状态判定、坐标重算、统计（纯函数）
- `js/store.js` —— 记录存取：标记、基准与界面状态的 localStorage 持久化
- `js/app.js` —— 页面交互：渲染与事件编排
