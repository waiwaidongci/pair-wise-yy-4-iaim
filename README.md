# 水下考古测绘基准校正与复核台

直接打开 `index.html` 使用。代码按职责分三个业务文件：

- `rules.js`（规则）：基准校验（方位/比例尺/误差必填，误差>5% 或比例尺缺失即不可用）、标记状态机（待校正/待复核/已复核）、坐标按基准重算。
- `store.js`（记录存取）：基准与标记的 localStorage 读写；每个潜次仅一个生效基准（同潜次保存即覆盖）；基准变更或更换潜次时关联标记自动重算、回到待复核，旧坐标留档但不计入统计；筛选/视图/当前潜次等界面状态持久化。
- `app.js`（页面交互）：地图、基准表单、标记表单、类型+状态筛选、列表/时间线切换、统计栏与导出。

规则要点：待校正标记不进入时间线和导出，且不可复核；基准修复后标记回到待复核，需人工复核通过才计为已复核。
